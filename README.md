# Prosper Nwachukwu — Developer Portfolio

A responsive personal portfolio built with React, TypeScript, Vite, and Lucide icons.

## Features
- Responsive navigation and sections for selected work, about, skills, and contact
- Project cards for MPAY and YP Foods
- Links to GitHub, LinkedIn, and email
- Custom CSS project illustrations; no screenshot assets required
- Mobile-friendly layout and reduced-motion support

## Run locally
1. Install a current Node.js LTS release from https://nodejs.org/
2. Run `npm install`
3. Run `npm run dev` and open the local Vite URL
4. Run `npm run build` to create a production build in `dist`

## Deploy on Vercel
Import this repository at https://vercel.com. Use build command `npm run build` and output directory `dist`. Vercel will provide an HTTPS URL when deployment succeeds.

## Project notes
- MPAY is presented as a frontend website concept. Live payment processing and backend financial features are not claimed.
- YP Foods is presented as a starter website/PWA concept; production authentication, database, payment, delivery, and notification services are not confirmed.
- Contact uses a `mailto:` link and does not require a backend.
